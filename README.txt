# My Photo Library

iPhone Safari向けの個人用写真集ビューアーです。

## 使い方
1. `index.html` をHTTPS対応の静的ホスティングに配置して開きます（IndexedDBを安定利用するため、`file://` 直開きよりHTTPSを推奨）。
2. 「写真集を追加」から画像を複数選択、またはPDFを選択します。
3. タイトルを入力して保存すると本棚に追加されます。
4. 表紙をタップして読み始めます。左右スワイプまたは前へ/次へでページ送り、拡大表示でピンチズームできます。
5. 本棚で各写真集を長押し（PCでは右クリック）すると削除できます。閲覧画面右上の「•••」からも削除できます。

## 保存とプライバシー
- 画像ページはIndexedDBに保存され、サイトのサーバーにはアップロードされません。
- PDFはブラウザ内でページ画像に変換して保存します。PDF.jsのライブラリをCDNから読み込むため、初回利用時はインターネット接続が必要です。
- 同じSafariの同じWebサイト内で利用します。別端末や別ブラウザとは同期しません。
- SafariのWebサイトデータ削除、プライベートブラウズ、端末の容量不足・ストレージ整理などでデータが消える可能性があります。原本は必ず別途保管してください。

## 公開について
自分専用にするには、HTTPSの静的ホスティングに置いたうえで、ホスティング側のアクセス制限やパスワード保護を設定してください。HTML自体にはログイン機能はありません。URLを知っている人がページを開くこと自体は防げないため、公開範囲の制御はホスティング側で行ってください。

## 注意
- ページめくりはCSS 3Dアニメーションによる軽量実装です。
- 大量ページ・高解像度PDFは端末メモリやSafariの保存容量に依存します。まず少量でテストしてください。
- 個人で利用する写真集の取り込みを想定しています。権利者の許諾なく複製物を公開・配布しないでください。


## カメラ自動スキャン（追加機能）
- 本棚の「カメラでスキャン」から背面カメラを起動します。
- OpenCV.jsでページらしい四角形の輪郭を検出し、安定して認識したら自動撮影します。
- 四隅を使った射影変換で傾き・台形歪みを補正し、軽い明るさ補正を行ってJPEG保存します。
- ページは撮影順に連番で1冊にまとめて保存されます。「保存して終了」で本棚に登録します。
- 「手動撮影」も利用できます。自動検出が難しい紙面では手動撮影を試してください。
- カメラとOpenCV.jsの利用にはHTTPSと初回インターネット接続が必要です。

## スキャン精度について
- 現状はページの四角形検出と射影補正です。綴じ目の湾曲を完全に平坦化する高度なデワープ処理ではありません。強い反りや見開き中央の歪みは残る場合があります。
- 光沢紙の反射、暗さ、ページと背景の色が近い場合は境界検出が不安定になります。明るく均一な照明、ページを平らに保つことを推奨します。
- 撮影後の画像は高品質JPEGで保存しますが、カメラの解像度とSafariのメモリ・保存容量に依存します。


## ホーム画面アプリ（PWA）
- Safariで開き、共有メニューから「ホーム画面に追加」を選ぶと、アプリ風の単独画面で起動します。
- `manifest.webmanifest` と `sw.js` によりアプリ名・アイコン・基本画面キャッシュを設定しています。
- 写真集データはIndexedDBに保存し、利用可能な場合は永続ストレージも要求します。ホーム画面アプリとSafariタブは別の保存領域になるため、ホーム画面アプリ側では写真集をあらためて取り込んでください。
- オフライン対応は画面の基本ファイルのみです。PDF.js/OpenCV.jsのCDN読み込みや新規スキャンはネット接続が必要です。
